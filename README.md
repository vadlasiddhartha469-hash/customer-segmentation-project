# Customer Segmentation Project

This project segments customers based on their behavior and demographics using K-Means Clustering.

## Key Profiles Identified:
- **Cluster 0:** High Income, Low Spenders (Potential for luxury targeting)
- **Cluster 1:** Low Income, High Spenders (Highly engaged, price-sensitive)
- **Cluster 2:** High Income, High Spenders (VIPs / Brand loyalists)
- **Cluster 3:** Low Income, Low Spenders (Occasional bargain buyers)
